## 2. 运行

```bash
go build -o inkvault .
./inkvault                    # 默认 http://127.0.0.1:8790
./inkvault -port 8791         # 指定端口
./inkvault -data ~/MyVault    # 指定数据目录
./inkvault -no-browser        # 不自动打开浏览器
./inkvault -bind 127.0.0.1    # 只允许本机访问
```

依赖：

- Go 1.24+
- 纯 Go SQLite（`modernc.org/sqlite`），**不需要 cgo**
- `golang.org/x/net/html`（HTML 解析）
- `golang.org/x/text`（GB18030 编码）
- `github.com/skip2/go-qrcode`（访问二维码）

## 3. 配置

`<data>/config.json`：

```json
{
  "port": 8790,
  "pin": "160124",
  "token": "e2e216ae...",
  "requireAuth": true,
  "publicUrl": "https://notes.example.vicp.net",
  "trustProxy": true,
  "forceHttps": false,
  "sessionDays": 180,
  "autoBackup": true,
  "backupKeep": 14,
  "backupEveryHours": 24,
  "vaultName": "我的知识库",
  "maxUploadMb": 64
}
```

- `pin` 首次启动随机生成，可在设置中修改。
- `token` 用于 App / 脚本的 `X-Ink-Token`。
- `publicUrl` 用于导出时的回链与二维码。
- `trustProxy` 打开后读取 `X-Forwarded-Proto/Host`。

## 4. 数据库

### 4.1 初始化

`store.Open(dir)`：

1. 创建数据目录与 `files/`；
2. 打开 SQLite，设置 WAL / busy_timeout / foreign_keys；
3. 执行 `schema`（`CREATE TABLE IF NOT EXISTS`）；
4. 尝试创建 FTS5 trigram 索引，失败则降级为 LIKE；
5. 增量迁移（`ALTER TABLE ... ADD COLUMN`）；
6. 首次启动写入默认笔记本「收集箱」；
7. 回填 `word_count` / `excerpt`。

### 4.2 主要索引

```sql
idx_notes_notebook    notes(notebook_uid)
idx_notes_updated     notes(updated_at)
idx_notes_deleted     notes(deleted_at)
idx_notes_status      notes(status)
idx_note_tags_tag     note_tags(tag_uid)
idx_attachments_note  attachments(note_uid)
idx_versions_note     note_versions(note_uid, id DESC)
notes_fts             FTS5(uid UNINDEXED, title, content, tokenize='trigram')
```

### 4.3 一致性策略

- 笔记、标签、字段值的手工级联在 store 层完成（无外键依赖，便于同步导入）；
- 删除笔记：软删除 → 回收站 → 永久删除时清理附件文件、版本、字段值、FTS；
- 备份使用 `VACUUM INTO` 生成一致性快照。

## 5. API

所有接口返回 JSON（除导出/文件流）。鉴权方式：

- Cookie `inkv_session`（浏览器登录后自动携带）
- Header `X-Ink-Token: <token>`（App/脚本）

未登录返回 `401 {"error":"需要登录"}`。

### 5.1 认证与基础

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ping` | 应用信息、是否需要登录（无需鉴权） |
| POST | `/api/login` | `{pin}` → 设置 Cookie，返回 token |
| POST | `/api/logout` | 清除会话 |
| GET | `/api/bootstrap` | 初始化数据：笔记本、标签、字段、模板、计数、统计、设置 |
| GET | `/api/settings` | 设置详情（含 PIN/Token/二维码） |
| PUT | `/api/settings` | 保存设置 |
| GET | `/api/audit` | 最近 200 条访问日志 |

### 5.5 示例

```bash
# 登录
curl -c cookie.txt -X POST http://127.0.0.1:8790/api/login \
  -H 'Content-Type: application/json' -d '{"pin":"160124"}'

# 搜索
curl -b cookie.txt 'http://127.0.0.1:8790/api/notes?q=%E6%9E%B6%E6%9E%84&limit=20'

# 导出目录（Excel）
curl -b cookie.txt -o 目录.xlsx \
  'http://127.0.0.1:8790/api/export/toc?format=xlsx&groupBy=notebook&summary=1'

# 导入 ENEX
curl -b cookie.txt -F 'file=@我的笔记.enex' http://127.0.0.1:8790/api/import
```

## 6. 导入实现细节

| 文件 | 关键点 |
| --- | --- |
| `importer.go` | 扩展名 + 内容嗅探；ZIP 解包拒绝 `..`；UTF-8/GB18030 解码；CSV 列名中英映射 |
| `enex.go` | `<en-media hash>` 按 MD5 匹配 `<resource>`；`<en-todo>` 转任务列表；跳过加密块 |
| `htmlmd.go` | 基于 `x/net/html` 的 DOM 遍历；标题/列表/表格/引用/代码/图片；未知标签解包 |
| `markdown.go` | 公共根目录剥离；Notion 32 位哈希清理；`![[img]]` 附件化；frontmatter 标签 |

附件占位符：`{{INKATT:0}}` → API 层保存后替换为 `/api/files/<uid>`。

## 7. 导出实现细节

- **DOCX**：`word/document.xml` + `styles.xml` + `footer1.xml`，A4 页边距，页脚页码。
- **XLSX**：多工作表、列宽、冻结首行、自动筛选、内联字符串、数字识别。
- **HTML**：内嵌 CSS，A4 阅读版式，封面 + 分组 + 条目卡片 + 打印样式。
- **ENEX**：`en-note` + `<resource>` base64，附件按 MD5 生成 `en-media`。
- **ZIP**：按笔记本建目录，附件集中 `_附件/`，Markdown 中的 `/api/files/uid` 改写为相对路径。

## 8. 前端

无打包步骤，直接原生 ES5/ES6 浏览器脚本：

| 文件 | 职责 |
| --- | --- |
| `icons.js` | 内联 SVG 图标库 + `data-icon` 水合 |
| `md.js` | Markdown 渲染（标题/列表/表格/任务/代码/引用/图片） |
| `core.js` | 状态、HTTP 适配、Modal/Drawer、Toast、工具函数 |
| `ui.js` | 侧栏、列表、编辑器、统计视图渲染 |
| `panels.js` | 目录导出、导入、设置、备份、同步、版本、命令面板 |
| `local.js` | 移动端离线适配器（IndexedDB + 同步） |
| `app.js` | 启动、登录、路由、自动保存、事件绑定、快捷键 |

存储适配器接口（`Store`）：

```
bootstrap / listNotes / getNote / createNote / updateNote / patchNote
deleteNote / restoreNote / purgeNote / duplicateNote / versions / restoreVersion
listNotebooks / createNotebook / updateNotebook / deleteNotebook
listTags / createTag / updateTag / deleteTag
stats / statsNote / settings / saveSettings
tocPreview / exportTOC / exportStats / exportNote / exportVault
importFile / importPreview / backups...
```

`HTTP` 与 `LocalStore` 实现同一套方法，UI 不感知运行模式。

## 9. 构建

### 桌面


```bash

  -configuration Release -sdk iphoneos -arch arm64 \
```

## 11. 已知限制

- 导入大小：单文件 128 MB、压缩包 512 MB、上传 64 MB（可调）。
- 目录导出最多 5,000 篇（避免一次渲染过大）。
- 移动端同步不含附件。
- FTS 索引在每次保存时增量更新；如出现异常可手动重建。
- 未实现列表虚拟滚动，超大列表建议配合筛选。
- 未实现应用层加密，依赖磁盘加密。

## 12. 版本与迁移

- 当前 `1.0.0`，数据库 schema 通过 `CREATE TABLE IF NOT EXISTS` + 增量 `ALTER` 演进。
- 备份 manifest 记录版本；恢复旧备份后如 schema 较旧，启动时会自动补齐缺列。
- 建议升级前先「立即备份」。
